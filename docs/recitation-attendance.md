# منع تسميع الطالب الغائب

تتعطل حقول الدرس وجنب الدرس والمراجعة والملاحظات وزر الحفظ عند تسجيل الطالب غائبًا أو معتذرًا في الحضور لنفس الحلقة وتاريخ التسميع. يمكن تغيير الطالب أو التاريخ دون إغلاق النموذج.

إذا لم يوجد سجل حضور، يُمنع التسجيل عند وجود حالة «غائب» في جلسة التسميع لنفس اليوم والحلقة. سجل الحضور الصريح هو المرجع: تصحيحه إلى «حاضر» أو «متأخر» يسمح بتسجيل الطالب الذي عاد للحلقة. عدم تسجيل الحضور وحده لا يمنع التسميع.

يُراجع الحضور عند فتح النموذج وتغيير الطالب أو التاريخ والرجوع للنافذة، ثم مرة أخرى قبل الحفظ. تعذر التحقق يمنع الحفظ مع رسالة واضحة. يمنع trigger خاص في قاعدة البيانات الإدخال والتعديل للغائب، حتى عند استخدام نموذج قديم أو الطلب المباشر. لا تُحذف السجلات السابقة ولا تُغير صلاحيات RLS.

الاختبارات: `npm run test:attendance`، و` scripts/verify-recitation-attendance.sql` داخل معاملة تنتهي بـ `rollback`، باستخدام طالب تجريبي معزول وصلاحيات معلم فعلي.
